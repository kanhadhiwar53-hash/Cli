# MovieBox Integration Starter

A Kotlin + XML Android starter project with a GitHub Actions workflow that builds a debug APK.

## Build

Push to `main` or run the **Build Debug APK** workflow manually. The APK is uploaded as a workflow artifact.

## Current scope

This is a clean starter scaffold, not a completed MovieBox API integration. The uploaded `.cs3` is compiled extension code; API authentication must be implemented only after its request flow is verified and against an authorized API. Do not commit access tokens, cookies, or private credentials.
